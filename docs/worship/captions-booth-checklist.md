# Captions booth checklist

Captions keep running when the page is not in front, but a browser can only do so much. Run this once on the
booth computer before a Sunday, and again after changing the computer, the browser, or its settings. Each
test: do it with captions live and a listener page open on a phone, then check what the listener sees.

## Keeps running (expect no gap)

1. **Switch to another tab for 10 minutes.** Do: start captions, speak, switch to a different tab and wait.
   Expect: the phone keeps showing "Live" and new captions when you speak. If it shows "interrupted": the
   browser is slowing the page; see Opera GX below.
2. **Minimize the window.** Do: minimize the browser for 5 minutes, then speak. Expect: captions continue.
3. **Go to Services and back.** Do: while live, open Services, then another page, then return to Captions.
   Expect: a purple pulsing microphone button appears at the bottom right on other pages; Captions still says
   Live when you come back, and nothing restarted.
4. **Let the screen dim.** Do: leave the computer idle for the length of your screen timeout. Expect: the
   screen stays on while live (it is kept awake), and captions continue.

## Recovers (expect a short gap)

5. **Reload the page.** Do: while live, press reload and confirm the browser's question. Expect: captions
   reconnect to the same session and link within a few seconds, with the same input, and the phone resumes.
   If the browser asks for the microphone again, choose Allow, then press Stop current session and Start
   captions.

## Ends (this is expected; the browser cannot do otherwise)

6. **Close the tab.** Expect: the browser asks first. Confirming ends captions; the phone shows the last
   lines for an hour.
7. **Put the computer to sleep.** Expect: captions stop; the phone shows "interrupted" after 15 seconds.
   Press Start captions again after waking (a silent session is replaced after 2 minutes).

## Opera GX

Opera GX can freeze or close background tabs to save memory (tab sleeping, the RAM limiter, "hot tabs
killer"). For the booth: turn these off for this site, or keep the captions page in its own window. After
changing the setting, repeat test 1.

## If a test fails

Write down which test, what the phone showed, and the time, and tell whoever maintains WorshipFlow.
